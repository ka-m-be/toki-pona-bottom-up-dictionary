## Material included in this repository

### `data/sources.json`: reference data from sona Linku (CC BY-SA 4.0)

- Source: Linku API v1 (`https://api.linku.la/v1/words?lang=tok`, retrieved 2026-10), dataset
  [lipu-linku/sona](https://github.com/lipu-linku/sona) by the Linku contributors, website
  [linku.la](https://linku.la).
- Licence: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) (data). The API code is GPL-3.0;
  no API code is included here.
- `data/sources.json` is an adaptation (a selection of fields per word: category, usage, Linku definition,
  ku data, English pu wording, resource links) and is **shared under CC BY-SA 4.0** as well. The attribution
  is repeated in the file's `meta` block and on every word page.
- Some fields that Linku relays have freer origins: the pu wording (public domain) and the ku data (CC0),
  see below. This project still treats the whole file as CC BY-SA 4.0.
- The German pu wording from Linku is not used: whether the 2026 public-domain declaration covers the German
  edition was not established, and Linku's German text is defective for `lawa` and `lukin`.

### pu wording (Sonja Lang, *Toki Pona: The Language of Good*, 2014): public domain

- The "Official Toki Pona Dictionary" (pp. 125–134) has been in the **public domain** since the 2014
  edition notice
  ([sona pona transcription](https://sona.pona.la/wiki/Source:Toki_Pona:_The_Language_of_Good/Official_Toki_Pona_Dictionary)).
  On 2026-04-14 Sonja Lang declared the whole 2014 English edition public domain
  ([post on X](https://x.com/tokipona/status/2043869843997299173)).

### ku data (Sonja Lang, *Toki Pona Dictionary*, 2021): CC0

- The book was released under **CC0** on 2026-01-12, except the cover and pp. 393–402
  ([Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Toki_Pona_Dictionary.pdf)).
- The ku data is also published at [https://tokipona.org/nimi_pu.txt](https://tokipona.org/nimi_pu.txt)
  (last updated 2021-05-04). That file asks: "If you use this data in your project, please provide a link
  back to this file." Link: https://tokipona.org/nimi_pu.txt (also on the Sources page of the app).

### `data/dictionary.json`: this project's own content (MIT)

- Toki Pona definitions, glosses in English, German and Spanish, learning order, layers and back-references,
  written by this project. The English and Spanish glosses are AI-assisted translations of the German
  project glosses.
